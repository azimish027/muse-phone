# 落砂成羽之刻

刻砂求羽，落砂成羽之刻。

一个精细化的时间块管理 H5 应用：日/周双视图时间网格、5/10/15/30 分钟颗粒度切换、时间轴拖拽创建/移动/拉伸时间块、快速文本解析录入、语音转文字录入、两级标签系统与按标签灰显过滤、标签时间占比统计（当天/本周/本月/自定义天数）、每日面板（天气/心情/任务/重要事项/小结）与文本清单/趋势图导出（周/月/自定义范围）、排期模板一键套用、图片周报、数据洞察与习惯连续性。数据按使用者身份隔离持久化。

## 功能

- 顶部功能区可整体收起：收起后顶部只留一个「展开」按钮（今天、日期切换、日/周、更多、标签筛选全部隐藏），状态记忆、下次进入保持；展开后第一行保留品牌/今天/日期导航/日/周/更多，第二行保留标签筛选条与「管理」入口
- 底部工具条统一只保留「快速添加 + 语音」两个按钮，标签管理与排期模板入口分别并入顶部筛选条「管理」与「更多」面板（排期模板位于主题与页面方案之后、标签统计之前）
- 日视图（单日 24h 纵向时间轴）与周视图（多天连续网格，7/14/21/28 天可选）
- 无限画布：双指捏合缩放、平移模式拖拽浏览、缩放比例记忆保存、一键适应视图；周视图提供“滚动到今天”定位按钮，触底自动加载更早记录
- 时间轴颗粒度切换：5 / 10 / 15 / 30 分钟（默认 30）
- 时间轴拖拽创建时间块、拖动移动（周视图可跨列改期）、拖动边缘拉伸调整时长
- 快速添加：文本解析（如 `14:00-15:30 产品评审`、`15:00 健身 1小时`、`明天10:00 晨会`）
- 语音输入转文字（ASR）：统一启停衔接、单飞保护与卡死兑底，麦克风权限被拒时给出系统设置引导，no-speech / network / engine 等失败提供一键重试，避免识别中途卡死或误报；转写文本回填输入框后进入解析确认流程
- AI 输入（底部语音按钮）：一句话同时安排时间块 / 任务 / 心情 / 重要事项 / 小结 / 计划，接入在线 AI 推理模型（灵光 AI Chat，结构化输出），调用前先检测环境是否提供 AI 能力，网络抖动自动重试一次，仍失败才回退本地规则解析；解析成功后会生成可编辑预览卡（勾选保留、改标题、改日期时间、删除）并标注「由在线 AI 模型推理解析」，确认后才落库；在线 AI 暂不可用时按原因提示（环境不支持 / 网络异常 / 返回格式异常）并自动回退本地规则，提供「重试在线解析」入口，仍可手动修改
- 两级标签系统：一级/二级标签、8 色预设、重命名、删除（时间块保留、标签置空）
- 按标签筛选：匹配事件正常显示，非匹配事件灰显保留位置
- 标签统计：当天/本周/本月/自定义天数范围各标签时间占比（时长、百分比与进度条），周视图逐日展示、月/自定义视图按周分组展示
- 按标签查看日均趋势：柱状趋势图 + 日均/活跃天数/单日峰值，支持按标签切换
- 按周汇总趋势：按自然周聚合时长柱状图（周均/单周峰值），可一键导出为带 ASCII 趋势图的 txt 文件
- 自定义天数汇总：输入 1-365 天范围（默认近 30 天）或快捷选择 7/14/30/90 天，以当前日期为结束日向前汇总
- 每日面板：天气（定位/手动城市/自动刷新）、今日心情快捷记录、任务清单（Emoji 分类、语音输入、勾选完成）、重要事项（📌 置顶记录）、今日小结（语音输入 + 颜文字快捷库）
- 表情库：预设表情包（心情/颜文字/学习工作/生活）可自选开关，上传图片可定义为自定义表情，心情与任务表情选择器、历史记录、分享文本均支持自定义表情
- 主题与布置体系：内置 5 套主题（彩色画布/深色沉浸/活泼卡通/商务质感/极简留白），每套主题 = 配色 + 边框样式（无线框/细描边/加粗）+ 圆角档位（紧凑/标准/圆润）+ 卡片密度（紧凑/舒适/留白）+ 今日面板排布（双栏/单栏）+ 卡片质感（实心/玻璃）+ 背景图案层（点阵/纸张/光斑/斜纹，纯 CSS 生成）
- 一句话主题配置：主题面板输入一句话（如「换成深色商务风，圆角大一点，主色用蓝色」），AI 在现有主题方案与可调参数（配色/圆角/密度/边框/卡片/图案/字体/字号）范围内自动切换与调整；AI 不可用时提示并回退到手动选项
- 「我的主题」库：自定义主题支持命名保存多套、另存为新主题、覆盖保存、重命名、复制、删除，一键切换；旧版单套自定义配色自动迁移为第一套自定义主题
- 主题透明度与背景图处理：图案透明度、按钮透明度可单独调节（0-100%）；支持从相册/相机上传自定义背景图片，可调图片透明度（0-100%）与模糊度（0-40px），预览卡同步展示效果
- 时间轴质感自定义：网格样式（横格/方格/空白/点阵）、背景透明度、网格线颜色与透明度、5 档线宽（极细/细/中/粗/特粗）与 4 种线型预设（实线/虚线/点线/点划线），随主题或页面存档保存
- 字体设置：全局字体颜色、字号档位（标准/放大）、字体预设（系统/圆体/宋体/黑体/楷体/等宽），随主题或页面存档保存
- 主题面板迷你预览卡：每个主题以小卡片同时展示配色、圆角、背景图案与卡片布局，切换前即可对比；切换主题时背景与卡片平滑过渡，并弹出应用成功轻提示
- 今日面板内容搜索与筛选：按关键词搜索任务/重要事项，按全部/未完成/已完成筛选任务
- 任务清单拖动排序：按住 ⋮⋮ 手柄上下拖动调整顺序；按住任务可拖到上方时间轴排期
- 放大延伸视图：全屏展示面板内容，双指捏合缩放字号（80%-170%，记忆保存），避免内容拥挤显示不全
- 一键复制分享：把当天面板整理成纯文本复制到剪贴板，可粘贴到任意聊天分享
- 历史记录回顾：查看近 30 天有记录的面板（心情/任务/事项/小结），可展开查看详情
- 文本清单导出：当前周 / 当前月 / 自定义范围全部时间块导出为 txt 保存到本地（按天明细或按标签汇总，含备注与合计）
- 排期模板：内置工作日/学习冲刺/健康作息/周末放松等常用模板，也可把某一天的排期存为自己的模板；选日期后一键套用批量生成时间块，再手动微调
- 模板包导入导出：模板可打包为本地 JSON 文件导出备份，换设备时导入即可迁移，后续可沉淀成模板库
- 图片周报：统计页按标签汇总时长、占比与明细，渲染成带主题风格的海报图（canvas），可保存到系统相册直接发周报
- 复盘闭环：周报图片生成后一键分享，配合按周保存的「周小结」（可一键从每日小结汇总），形成记录→复盘→分享完整链路
- 新手引导：首次进入弹出分步引导（建块/打标签/模板与周报/复盘闭环），右上角可跳过，看过一次后不再出现
- 源码包导出：更多设置中一键把当前版本完整源代码打包为 zip 保存到本地，方便备份或迁移
- 数据洞察：时间流向图（24 小时分布条形图）+ 标签占比环形图，让「时间花在哪」一眼可见
- 习惯连续性：连续记录天数、本周达成天数（周一至周日达成条带）、本月活跃天数等轻量化激励

## 技术结构

- React 18 + TypeScript + Vite + Tailwind
- 数据存储：DB（`time_blocks`、`tags`，user 表，按使用者隔离）；每日面板为单人单设备轻量记录，使用 localStorage
- 语音识别：ASR（`window.lingguang.asr`），统一封装于 `src/hooks/useVoiceInput.ts`（启停衔接 / 权限引导 / 失败重试 / 卡死兑底）
- AI 理解层：AI Chat（`window.lingguang.ai.chat`，json_schema 结构化输出，含环境能力检测、一次自动重试与返回格式兑底），封装于 `src/lib/ai.ts`（日程意图解析 + 本地兜底 + 主题参数解析）
- 天气：公开天气数据接口（`window.lingguang.data.getWeather`）+ 定位（`window.lingguang.getLocation`）
- 触感反馈：VIBRATE
