# 应用设计文档

## 1. 文档基本信息
- **用户原始需求**: 创建一个精细化时间管理应用，包含周视图和日视图，时间轴支持30分钟颗粒度，可以在时间轴上拖拽创建时间块、拉伸调整时长，并支持语音输入转文字功能
- **轻应用标题**: 时间块
- **日期**: 2026-10-16
- **需求类型**: 基于历史需求延续（对已有方案修改）
- **关键信息来源**: 当前需求 / 创建方案 / 历史对话
- **相关历史对话摘要**: 用户核心诉求为“数字化的效率工具”而非“电子化手帐”：不需要手写模拟、贴纸美化，要求极致视图操作、高自定义时间颗粒度、便捷输入（打字/语音）与强大标签系统，对标三星日历但颗粒度更细；视觉参考 Notion Calendar / Cron / 飞书日历的极简高效信息层级。技术形态确定为灵光闪应用（H5），原生 App 能力（系统日历导入、桌面小组件等）不纳入本产品边界。
- **相关用户记忆摘要**: 无额外稳定偏好；用户强调“拒绝手写模拟”“极简、高效、无纸化”，输入方式限定为键盘与语音。
- **核心价值**: 精细时间块视图与高效记录
- **能力列表**: ["ASR", "DB", "VIBRATE"]

## 2. 目标用户与使用场景
- **目标用户**: 需要精细规划每日/每周时间的个人用户（学生、自由职业者、远程办公者、习惯自我管理者），追求快速录入和可视化时间分配，而非手帐式记录。
- **核心场景**: 用户希望以 30 分钟（可细到 5 分钟）的时间块颗粒度规划一天或一周：在时间轴上直接拖拽圈出时间段，快速填写标题和标签；走路或手忙时用语音直接说“明天上午十点到十一点半健身”完成录入；通过两级标签对时间块分类着色，按标签灰显过滤查看某类时间占比。数据需要在自己再次打开应用时完整保留，形成可持续的时间记录。
- **产品定义**: 一个单页工作台式的精细时间管理 H5 应用，提供日视图/周视图双时间网格、5/10/15/30 分钟颗粒度切换、时间轴拖拽创建/移动/拉伸时间块、快速文本解析录入、语音转文字录入、扁平两级标签系统与按标签灰显过滤。数据为使用者个人私有，按使用者身份隔离持久化。
- **产品目标**: 用户能在 10 秒内完成一次时间块录入（拖拽或快速输入或语音任一路径）；时间块创建后可移动、拉伸、改标签；再次进入应用后所有时间块与标签完整保留；周/日视图与筛选能帮助用户看清某天/某周的时间分配。

### 3.1 核心功能
1. 周/日双视图时间网格
   - 需求来源：用户明确指令
   - 解决问题：以精细时间轴查看一天或一周的安排，是全部记录与操作的主画布
   - 用户操作：顶部切换“日/周”视图；‹ › 切换日期/周；点击“今天”回到当前日期
   - 系统处理：按当前选中日期渲染日视图（0:00–24:00 纵向时间轴、左侧时间刻度、右侧事件区）或周视图（本周一至周日 7 列 + 共享时间刻度）；从存储读取当前范围时间块，按日期与开始分钟定位渲染
   - 结果反馈：时间块出现在对应时间位置，按标签颜色显示；今天日期高亮；空时段保留网格结构；当前时间显示红色指示线
   - 关键规则 / 约束：周视图固定周一到周日；切换视图保留当前选中日期；首版时间块为单日事件，不支持跨日；时间块在网格中允许重叠显示（不做自动避让，编辑面板可见时间范围）
2. 时间轴颗粒度切换（默认 30 分钟，支持 5/10/15/30）
   - 需求来源：用户明确指令（30 分钟）+ 创建方案承诺（5/10/15/30）
   - 解决问题：在细粒度规划和可读性之间自由调节时间网格
   - 用户操作：顶部颗粒度分段控件选择 5/10/15/30 分钟
   - 系统处理：调整网格辅助线密度（30 分钟主格线始终保留，更细颗粒度增加细辅助线），并将拖拽吸附、拉伸步长、快速输入补全粒度统一切换为当前颗粒度
   - 结果反馈：网格细分或合并，新建/移动/拉伸立即按新步长吸附
   - 关键规则 / 约束：默认 30 分钟；切换颗粒度不改变已有时间块的实际起止时间，仅影响网格显示与后续操作吸附步长
3. 拖拽创建时间块
   - 需求来源：用户明确指令
   - 解决问题：不打开表单，直接在时间轴上“圈出”一段时间形成事件
   - 用户操作：在时间轴空白处按下并纵向拖动（日视图单列；周视图在某一列内拖动）
   - 系统处理：以按下位置为起点、当前位置为终点计算时间范围，按当前颗粒度吸附；拖动过程显示半透明预览块
   - 结果反馈：预览块跟随指针并吸附网格；松手后若时长达到 1 个颗粒度，创建草稿并打开编辑面板（预填标题“新时间块”、起止时间），保存后正式写入；拖动距离不足 1 个颗粒度视为点击空白：打开快速添加面板并预填该时间段（默认 1 个颗粒度）
   - 关键规则 / 约束：最小时长 1 个颗粒度；范围不超过 0:00–24:00；松手未保存前为草稿态，取消则不写入
4. 拖动移动与拉伸调整时长
   - 需求来源：用户明确指令
   - 解决问题：已有安排需要改期或调整时长时，不重填表单
   - 用户操作：拖动时间块整体上下移动（周视图可横向拖动跨列改日期）；拖动块底部（或顶部）拉伸把手调整时长
   - 系统处理：按当前颗粒度吸附计算新开始/结束时间与日期，实时预览，松手后保存
   - 结果反馈：块位置/时长即时更新，保存后回读一致；到达 0:00/24:00 边界时钳制
   - 关键规则 / 约束：结束时间必须大于开始时间；拉伸最小 1 个颗粒度；移动/拉伸均不超过当日边界；移动/拉伸中给出触感反馈
5. 快速添加（键盘快捷输入）
   - 需求来源：创建方案承诺（纯键盘快捷输入）
   - 解决问题：打字最快完成录入，输入一句文本即生成时间块
   - 用户操作：点击底部“+ 快速添加”打开面板，在输入框输入如“14:00-15:30 产品评审”“15:00 健身 1小时”等句式
   - 系统处理：解析时间范围与标题，生成解析预览（日期、开始、结束、标题、标签）；确认后创建时间块并关闭面板
   - 结果反馈：预览卡即时显示解析结果；解析失败显示具体原因，用户可直接在下方字段手动修正后确认
   - 关键规则 / 约束：支持“HH:mm-HH:mm 标题”“HH:mm 标题 N分钟/小时”句式；缺少时间时按当前时间或当前颗粒度补全；标题为空默认“新时间块”；标签在字段区选择，默认无标签
6. 语音输入转文字创建时间块
   - 需求来源：用户明确指令
   - 解决问题：不方便打字时直接说话完成录入
   - 用户操作：在快速添加面板或底部工具条点击语音按钮，开始说话，点击停止
   - 系统处理：ASR 将语音转为文本，填入快速添加输入框，进入与手输一致的解析预览流程
   - 结果反馈：转写文本出现在输入框；随后展示解析预览；识别中显示“正在聆听…”状态与停止按钮；识别失败显示“未能识别，请重试或直接输入”，保留输入路径
   - 关键规则 / 约束：ASR 仅输出文字，不录制或保存音频；识别结果必须先经用户确认才创建；语音按钮在识别中防重复触发
7. 两级标签系统与颜色管理
   - 需求来源：创建方案承诺
   - 解决问题：用标签对时间块分类着色，形成“工作/会议、生活/健身”等层级认知
   - 用户操作：在标签管理面板新增一级标签、在其下新增二级标签，为标签选择颜色；可重命名、删除
   - 系统处理：保存标签名称、颜色、父子层级（最多两级）
   - 结果反馈：标签出现在筛选条与编辑面板的标签选择器中；时间块以标签颜色着色（左侧色条 + 浅色填充）
   - 关键规则 / 约束：最多两级；同一标签名下不可重名；删除标签前确认弹窗说明“该标签下的时间块将变为无标签”；删除后时间块保留、标签置空
8. 按标签筛选（灰显过滤）
   - 需求来源：创建方案承诺
   - 解决问题：快速查看某类时间安排在全天的分布
   - 用户操作：点击筛选条中的标签 chip（含“全部”）
   - 系统处理：当前视图内匹配事件正常显示，非匹配事件灰显降透明（保留位置与时长，便于看到分布）
   - 结果反馈：筛选条高亮选中标签；再次点击或点“全部”取消筛选
   - 关键规则 / 约束：选中一级标签时匹配其下所有二级标签；筛选为单选；筛选状态在日/周视图间切换时保留

### 3.2 扩展功能 / 暂不纳入首版
| 功能 | 来源 | 首版处理 | 理由 / 纳入条件 |
| --- | --- | --- | --- |
| 统计报告（按标签/按日/按周汇总时长） | 历史方案后期批次 | 暂不纳入首版 | 用户历史方案将统计放在同步之后的批次；数据模型已保留完整字段，后续可直接聚合 |
| 重复事件 / 多日事件 | 历史方案后期批次 | 暂不纳入首版 | 首版聚焦单日精细时间块与拖拽手感，重复规则会显著增加编辑面板复杂度 |
| 事件备注富文本 / 附件 | 无 | 暂不纳入首版 | 首版备注为单行文本，足够支撑记录闭环 |
| 时间块自动避让与冲突提示 | 基础可用推断 | 暂不纳入首版 | 允许重叠显示；冲突提示在时间块增多后按需纳入 |
| 跨设备同步 / 系统日历导入 | 平台能力边界 | 暂不纳入首版 | 灵光闪应用不提供系统日历导入与跨端同步能力 |

### 3.3 核心使用路径
- **代表性核心场景**: 用户 2026-10-16（周五）打开应用，默认进入日视图显示今天 0:00–24:00 时间轴（30 分钟颗粒度）。顶部“今天”按钮高亮当前日期。用户在 14:00 处按下拖动到 15:30，出现半透明预览块并按 30 分钟吸附，松手后弹出编辑面板，输入标题“产品评审”，选择“工作 > 会议”标签，保存；时间轴上出现蓝色会议块。随后用户点击底部语音按钮说“明天上午十点到十一点半健身”，转写文本填入输入框，解析预览显示“2026-10-17 10:00–11:30 健身”，用户确认创建。顶部切换到周视图（2026-10-12 至 10-18），拖动本周末某列空白创建“家庭聚餐”，再拖动该块横向到周日列完成改期。点击筛选条“工作”标签，其余事件灰显。次日重新打开应用，“今天”回到 10-17，昨天创建的时间块与标签均完整保留（DB 按使用者隔离读取）。
- **失败/恢复路径**: 快速添加解析失败 → 面板内显示原因，字段可手动修正；语音识别失败 → 提示并保留手动输入；拖拽误操作 → 未达 1 个颗粒度不创建；删除标签 → 确认弹窗说明影响；数据读取失败 → 时间轴保留网格骨架并显示错误条与重试入口，不伪装成空数据。

### 3.4 角色 / 端 / 权限识别
- **需要管理员 UI 分流**: 否
- **is_multi_role**: 否
- **role_signals**: 无（个人时间管理工具；需求未涉及共享日程、他人可见、审批汇总或管理方查看使用者数据）
- **manager_user_defaults**: 无
- **manager_ui_split**: 否
- **roles**:
  - **name**: 使用方（每位使用者，包括闪应用创建者与后续打开 H5 的普通用户，业务功能一视同仁）
    - **entry**: 不分角色入口（同一界面同一权限）
    - **core_tasks**: 查看日/周视图、拖拽创建/移动/拉伸时间块、快速添加与语音录入、两级标签管理与筛选
    - **visible_data**: 仅本人创建的时间块与标签
    - **allowed_actions**: 对本人时间块与标签的新增、查看、编辑、删除
    - **restricted_actions**: 无法查看或修改其他使用者的任何数据；无管理方入口
- **数据对象 1**: 时间块记录
  - **业务目的**: 记录用户每天的时间安排（标题、日期、起止分钟、标签、备注），支撑视图渲染、拖拽编辑与历史保留
  - **创建来源**: 用户个人产生（任意使用者在应用内为自己的日程创建，属普通业务动作，非平台管理动作）
  - **管理员**: 不适用（个人工具，无管理方业务语义；DB 框架下管理员与普通用户一视同仁）
  - **普通用户**: 只读写自己的（每位使用者只读写自己创建的时间块）
  - **普通用户之间可见性**: 互相不可见（个人数据隔离）
  - **table_kind**: user
  - **需要管理员 UI 分流**: 否
  - **需要业务 owner UI 分流**: 否（数据天然按使用者身份隔离，无 owner 与参与者之分）
  - **owner 判定依据**: 不需要（数据按使用者的稳定身份隔离，无公开记录场景）
  - **是否需要定位当前用户自己的公开记录**: 不需要（时间块为个人私有数据，无公开记录场景）
  - **管理方参与普通流程时的本人状态**: 不适用
  - **table_kind 选择理由**: 时间块是个人私有且持续增长的多条记录，仅本人增删改查、其他使用者不可见、管理方无需汇总，故用 user 模式实现按使用者隔离。
- **数据对象 2**: 标签
  - **业务目的**: 承载两级扁平标签（名称、颜色、父子层级），供时间块着色、筛选与分类管理
  - **创建来源**: 用户个人产生（任意使用者为自己维护的私有标签体系）
  - **管理员**: 不适用（同数据对象 1）
  - **普通用户**: 只读写自己的（每位使用者只读写自己的标签）
  - **普通用户之间可见性**: 互相不可见
  - **table_kind**: user
  - **需要管理员 UI 分流**: 否
  - **需要业务 owner UI 分流**: 否
  - **owner 判定依据**: 不需要
  - **是否需要定位当前用户自己的公开记录**: 不需要（标签为个人私有配置）
  - **管理方参与普通流程时的本人状态**: 不适用
  - **table_kind 选择理由**: 标签是使用者个人的分类配置且与时间块同属私有数据，仅本人维护，故同样用 user 模式。
- **state_sharing**: 单人本地（每位使用者各自独立使用，跨用户无任何共享、公开或协作语义）
- **implementation_boundary**: 无多人共享需求；时间块与标签均为个人私有数据，按使用者稳定身份隔离存取（DB 用户隔离），不涉及服务端汇总、审核或管理方视角。

### 4.3 核心页面详细设计
#### 日程工作台
- **页面目标**：提供今天/本周的精细时间视图，并承载拖拽创建、移动、拉伸、筛选全部主操作
- **布局骨架**：自定义顶部导航（安全区 padding 后：第一行 48px：左侧“今天”文本按钮 + 日期范围标题（日视图“2026年10月16日 周五”/周视图“10月12日-18日”）；右侧视图分段控件（日/周）+ 颗粒度分段控件（5/10/15/30）；第二行 36px 标签筛选横滑条（“全部”+ 各级标签 chip，末尾“管理”入口）。时间轴画布 flex-1 唯一滚动区：左侧刻度列固定 48px（每 30 分钟一格刻度文字，整点加粗），事件区相对定位；30 分钟主格线贯穿，细颗粒度时叠加更浅辅助线；当前时间红色横线+左侧红点。底部工具条固定 56px+safe-area：主按钮“+ 快速添加”（flex-1，indigo 实底）＋语音图标按钮＋标签图标按钮（44px 触达区）
- **首屏内容层次**：无需滚动可见——日期导航行、筛选条、当前时刻前后约 2-3 小时的 30 分钟网格与已有事件块、当前时间红线、底部主按钮；视线由日期区自然落到时间轴
- **视觉保真要点**：保留“网格骨架永在”的构图：空态/加载/失败都不移除网格与刻度；事件块统一左色条+浅填充；今天日期为 indigo 圆底白字；筛选激活时非匹配块 opacity 降至 0.25 并保留原位
- **核心区块**：
  - 日期导航行：今天按钮、日期标题（点击可展开日期选择，首版提供 ‹ › 逐日/逐周切换即可）、视图与颗粒度分段控件
  - 标签筛选条：横滑 chip 列表，选中态为标签色实底或 indigo
  - 时间轴画布：刻度列 + 网格线 + 事件块（标题单行截断、可选标签色条）+ 当前时间线；周视图在画布顶部加 7 列日期头（周一至周日，今天高亮）
  - 底部工具条：主按钮“+ 快速添加”+ 语音 + 标签管理入口
- **主要动作与反馈**：
  - 拖拽空白 → 预览块吸附网格 → 松手打开编辑面板（成功）；不足 1 颗粒度 → 打开快速添加面板并预填时间段（点击路径）
  - 拖动/拉伸块 → 位置时长即时更新 + 触感 → 保存后回读（成功）；越界 → 钳制（边界反馈）
  - 切换视图/颗粒度/日期 → 内容 160ms 淡切 → 网格与块重排（成功）；无失败态
  - 标签筛选 → 非匹配块灰显（成功）；点“全部”恢复
  - 数据读取失败 → 网格上方红色错误条“加载失败，点击重试”+ 重试按钮；不显示空数据
- **跳转与衔接**：工作台 ↔ 快速添加面板（底部工具条/点击空白）↔ 事件编辑面板（点击事件块）↔ 标签管理面板（工具条“标签”）；面板关闭后回读当前视图

#### 快速添加面板
- **页面目标**：一条路径完成“文本或语音 → 解析确认 → 创建时间块”
- **布局骨架**：底部抽屉（圆角 20px 白色表面，轻遮罩 ≤0.18）：顶部标题行“快速添加”+关闭按钮；输入区：全宽 textarea（自动聚焦，2 行高）+ 输入框内右侧语音图标按钮；解析预览卡（成功：日期、起止时间、标题摘要、标签选择；失败：红色原因说明“未能识别时间格式，请手动填写”）；字段表单（标题、日期、开始、结束、标签选择器）；内容流末尾确认主按钮（全宽 indigo）+ 取消次按钮；面板整体可滚动，键盘弹出时确认按钮仍可达
- **首屏内容层次**：输入框 + 语音按钮为第一焦点；输入后预览卡即时出现；字段表单补充细节
- **视觉保真要点**：解析预览卡与事件块同语言（左色条+浅填充，随所选标签变色）；解析成功/失败两种卡态有明确视觉差异（成功=正常表面，失败=红边+红色原因文字）
- **核心区块**：输入区（含语音）、解析预览卡、字段表单、确认区
- **主要动作与反馈**：
  - 输入文本 → 实时解析（防抖 500ms）→ 预览卡更新；解析失败 → 红色原因 + 字段可手改
  - 语音按钮 → “正在聆听…”态 + 停止按钮 → 转写文本回填输入框 → 进入解析
  - 确认 → 保存中（按钮 loading）→ 成功后关闭面板、时间轴出现新块并回读；保存失败 → 面板内错误条，输入保留
- **跳转与衔接**：由工作台进入；取消/关闭返回工作台；创建成功后回读刷新当前视图

#### 事件编辑面板
- **页面目标**：查看、修改、删除一个已有时间块
- **布局骨架**：底部抽屉，顶部标题行（“时间块”+关闭）；字段表单：标题（输入框）、日期、开始时间、结束时间（步进选择器，步长=当前颗粒度，含校验文案“结束时间需晚于开始时间”）、标签选择器（含“无标签”）、备注（单行输入）；内容流末尾：主按钮“保存”+ 危险按钮“删除”（红色文字，点击弹出确认弹窗“删除该时间块？删除后不可恢复”）
- **首屏内容层次**：标题与起止时间为第一层；标签、备注为第二层；保存与删除在末尾稳定可见
- **视觉保真要点**：时间字段用等宽数字排版；标签选择器以标签色圆点+名称列表呈现，选中态带色描边
- **主要动作与反馈**：
  - 修改字段 → 校验（结束>开始）→ 保存 → 关闭并回读，时间轴更新（成功）；校验失败 → 字段下方红色提示，不清空输入
  - 删除 → 确认弹窗 → 删除并回读，时间轴移除该块（成功）；取消保留
  - 保存失败 → 面板内错误条 + 保留编辑内容，可重试
- **跳转与衔接**：由点击事件块进入；关闭返回工作台；删除确认弹窗为面板内模态

#### 标签管理面板
- **页面目标**：维护两级标签与颜色，支撑着色与筛选
- **布局骨架**：底部抽屉，顶部标题行“标签管理”+关闭；标签层级列表：每个一级标签为一组（名称 + 颜色圆点 + 右侧“新增二级/重命名/删除”图标按钮），其下二级标签缩进 16px 列表（每项 44px 触达区，同名交互）；底部“+ 新增一级标签”按钮；标签编辑形态（改名输入 + 8 色预设色板 + 保存/取消）；删除弹窗说明“该标签下的时间块将变为无标签”
- **首屏内容层次**：已有标签层级列表为主，新增按钮为次
- **视觉保真要点**：层级通过缩进与组间 1px 分隔线表达；颜色选择以标签色圆点网格呈现，选中带描边
- **主要动作与反馈**：
  - 新增/重命名/换色 → 保存 → 列表更新并回读（成功）；重名 → 红色提示
  - 删除 → 确认弹窗 → 删除后时间块保留、标签置空（成功）
  - 保存失败 → 错误条 + 输入保留
- **跳转与衔接**：由工作台工具条进入；关闭返回工作台，筛选条与编辑面板同步更新

## 5. 视觉与交互系统
### 5.1 设计概念与整体风格
- **设计概念**：把“时间”画成一张可编辑的图纸——浅灰底上，30 分钟网格线横贯屏幕，当前时间以红色细线标记，每个时间块是一块带着标签色左条的浅色色板；用户第一眼看到的是“今天的时间地图”，视线从日期标题落到网格，再落到底部主按钮与空白网格两条录入入口
- **风格族选择**：密集信息网格工作台——以时间网格为唯一视觉结构，信息密度高、层级由网格与色块建立、零装饰
- **风格定位**：极简、高效、无纸化；克制配色（浅灰底、白表面、indigo 主操作、标签色体系）；排版以清晰的时间数字与单行标题为骨架；交互以直接操纵（拖拽）为主
- **主动视觉系统**：首屏空间关系为“网格是主体、块是内容、导航是紧凑的边框”。布局上时间轴占满剩余高度；色彩上底色浅灰、网格线两层（主 30 分钟线 / 细颗粒度辅助线）、事件块由标签色驱动；字体上时间刻度用等宽数字、标题单行截断；图标统一 20px 线性；动效上拖拽吸附、面板滑动、筛选灰显均服务于直接操纵的即时反馈
- **媒介隐喻 / 视觉母题**：无——时间网格是工具的字面结构，不套用任何装饰性媒介；信息组织本身已构成视觉语言
- **视觉方向关键词**：密集网格、极简工作台、色块编码、等宽数字、直接操纵
- **界面气质参考**：Notion Calendar / Cron / 飞书日历的信息密度、克制配色与拖拽流畅感，不照搬具体品牌页面
- **为何适配当前需求**：用户明确拒绝手写模拟与贴纸美化，要求“极致视图操作、高自定义颗粒度、高效输入”；网格工作台正是信息密度与操作效率的视觉表达，标签色块让时间分配一目了然
- **视觉记忆点**：拖拽圈选时半透明预览块吸附网格的瞬间（30 分钟步长、轻微回弹 + 触感）——这是本产品区别于普通日历的核心交互记忆
- **主体 / 角色视觉设定**：无角色或品牌物
- **关键状态视觉映射**：当前时间=红色细线+红点；今天=日期 indigo 圆底白字；拖拽中=半透明预览块+吸附回弹；筛选激活=非匹配块 opacity 0.25；加载=网格骨架+轻量占位条；空态=网格保留+提示条“拖动创建时间块，或使用快速添加”；失败=网格上方红色错误条+重试；保存中=确认按钮 loading 态
- **图标 / 插画语言**：统一使用 lucide 线性图标：20px 光学尺寸、stroke 2、圆头端点、负形简洁；选中/按压态为底色变化（浅灰→indigo 浅底）；按钮图标随文字按钮，图标按钮 44px 触达区；不使用 emoji 或手写 SVG 承担主要图标
- **选项 / 词典小图标方案**：标签 chip 前用 10px 标签色圆点表达颜色，属代码原生图形；无成套生成小图需求
- **内容对象展示策略**：时间块为信息优先的网格对象（左色条+浅填充+单行标题+时间小字），不依赖图片；对象识别靠颜色与时间位置，图片不稳定问题不存在
- **图片角色 / image_mode**：code_native——视觉身份由网格、色块、排版、图标构成，无图片叙事职责
- **图片来源 × 职责 × 落点规划**：无图片资产；背景为纯色浅灰底色（代码原生），不引入纹理或生成图
- **关键图片共构与显示边界**：无
- **首屏核心对象资产检查**：无（首屏核心对象为网格与时间块，全部代码原生）
- **字体气质策略**：标题/品牌字=系统中粗黑体（PingFang SC/Segoe UI 600-700），紧凑工具感；正文=系统黑体 400/500；时间数字=等宽数字（tabular-nums）强调刻度精确性；按钮标签=中粗 15px

### 5.3 组件与动效表现
- **导航 / 入口组件**：自定义顶部导航（日期标题 + 今天按钮 + 视图/颗粒度分段控件）；底部工具条（主按钮 + 语音 + 标签图标，固定于容器底部，含安全区 padding，与面板打开互斥）
- **主内容组件**：时间轴画布（刻度列 + 双层网格线 + 当前时间线 + 事件块）；事件块（左色条 + 浅填充 + 单行标题 + 时间小字，40px 最小高度 = 30 分钟）；快速添加输入框（textarea 全宽 + 内嵌语音按钮）；标签筛选条（横滑 chip）；解析预览卡；标签层级列表
- **反馈组件**：面板内错误条（红底红字，含原因与重试/修正）；删除确认弹窗（居中模态，遮罩 + 明确按钮）；骨架态（网格 + 轻量占位条）；空态（网格保留 + 提示条）；语音聆听态（输入框上方“正在聆听…”+ 停止按钮）
- **按钮与图标语言**：主按钮=indigo 实底 48px 圆角 12px 白字；次按钮=浅灰底深字；危险按钮=红字；图标按钮=44px 触达区、lucide 20px、浅灰圆底按压加深；chip=32px 圆角 16px，选中实底；全部图标统一线性 20px，不使用 emoji 或英文 key 作为可见文案
- **跨页面组件保真**：工作台与三个面板共享标题层级（18px 面板标题 / 14px 区块标题）、按钮语言、chip 语言、事件块色块语法、图标、错误/空态文案结构；面板不被降级为裸表单——解析预览卡、标签色选择器、层级列表延续工作台的色块语言
- **跨页面视觉一致性**：工作台用网格+色块组织；快速添加面板用“输入→预览卡（色块语法）→字段”组织；编辑面板用字段+色块标签选择器；标签面板用层级列表+色点组织；四者共享 indigo 主操作、标签色、等宽数字时间、8-12px 圆角家族与同一动效节奏
- **全屏 / 沉浸式退出控件**：语音聆听态为非全屏面板内状态，面板右上角关闭按钮始终可见（44px 触达区、白底图标），停止聆听后关闭面板返回工作台
- **选项网格 / 词典卡片图标**：无（标签为列表 + 色点，无条目图标需求）
- **连续选择器 / 索引控件**：颗粒度=4 段分段控件（5/10/15/30）；日期切换=‹ › 逐日/逐周 + 今天；时间字段=步进时间选择器（步长=当前颗粒度，含上/下微调与直接输入）；不使用胶囊按钮排替代时间选择
- **数值范围 / 区间筛选控件**：时间起止为离散步长选择（步长=当前颗粒度，0:00–24:00 闭区间，校验结束>开始），在编辑面板中以成对步进选择器呈现（单列纵向，避免挤压）；事件时长由拖拽拉伸直接操纵，编辑面板提供精确值修正
- **代表性交互模式**：拖拽创建/移动/拉伸（直接操纵）、点击事件打开编辑面板、chip 筛选灰显、分段控件切换视图与颗粒度
- **核心动作可验收链路**：
  - 拖拽创建：pointerdown 空白 → preview 预览块（吸附）→ pointerup 时长≥1 颗粒度 → 打开编辑面板（草稿态）→ 保存 → 写入 DB → 回读 → 时间轴出现正式块；时长不足 → 打开快速添加面板预填时间段
  - 快速添加：输入 → 防抖解析 → 预览卡（成功/失败两分支）→ 确认 → 写入 → 回读 → 面板关闭出现新块
  - 语音：点击语音 → 聆听态（render-driving state=voiceState）→ ASR 返回文本 → 回填输入框 → 进入解析 → 确认创建；失败 → 错误态 + 手动输入保留
  - 保存/删除：确认 → loading → 写入/删除 → 回读当前视图 → 成功可见；失败 → 错误条 + 输入保留
- **核心输出可见性约束**：时间轴为唯一核心输出区，进入核心态后 0.5s 内必须看到网格与事件块；底部工具条不与面板竞争（面板打开即隐藏工具条）；固定元素不遮挡网格首屏 2-3 小时可见范围
- **弹层与遮罩可见性约束**：三个底部面板共享轻遮罩 rgba(0,0,0,0.18)，遮罩与面板同生同灭；关闭按钮与确认按钮在键盘弹出时仍可见（面板滚动）；删除确认弹窗使用较强遮罩 rgba(0,0,0,0.4) 且前景居中完整可见
- **终态与恢复链路**：删除确认→取消保留/确认删除后回读；解析失败→修正后确认或取消；语音失败→重试或手输；保存失败→重试；面板取消→草稿丢弃且时间轴无残留；所有终态均可返回工作台继续操作
- **行为绑定动效**：
  - 拖拽创建/移动/拉伸 → 预览块跟随指针 → 吸附时轻微回弹（120ms，easing_primary）+ VIBRATE 触感 → 直接操纵的即时感
  - 松手创建草稿 → 预览块淡入为编辑态（150ms fade）→ 反馈“已圈选，待确认”
  - 面板打开/关闭 → translateY 100%→0 / 0→100%，240ms，easing_emphasis → 明确的层次进入
  - 标签筛选 → 非匹配块 opacity 1→0.25，200ms，easing_primary → 保留空间语境的聚焦
  - 视图/颗粒度切换 → 内容 160ms 淡切 → 轻快切换不打断扫读
- **状态转场动效**：日期/周切换淡切 160ms；筛选取消反向 200ms；保存成功回读时新块 120ms 缩放淡入
- **首屏 / 首次进入动效**：网格静态呈现（不逐线动画），当前时间红线 400ms 缓入，今天高亮同步出现——克制，避免工具感被破坏
- **核心结果态表现**：保存成功 = 新块以标签色 120ms 缩放淡入并伴随轻微触感；删除成功 = 块 160ms 淡出后回读；错误 = 面板内红色错误条 200ms 滑入
- **节奏约束**：拖拽即时（<60ms 响应预览）；面板 240ms；状态切换 120-200ms；整体轻快稳定，不做装饰性长动画
- **禁止出现的通用处理**：不使用整页 loading 遮罩替代网格；不用 emoji 作为空态插画或条目图标；不做无业务职责的渐变/毛玻璃装饰；筛选不直接隐藏非匹配事件（保留灰显位置）
